보험 특약 MVP v7 — 전체 특약 마스터 구조 1차

현재 포함: 30개 주요 치료 특약
공통 설명 그룹 후보: 23개

핵심:
- rider-master.json / csv: 특약 마스터
- coverage-groups.json: 보장 본질이 같은 특약의 공통 설명 그룹 후보
- priority_display: 암·뇌·심장·순환계 치료 특약 상단 노출
- contract_variant: 갱신/LH 등 계약형태 별도 보존
- 진단 특약은 우선노출에서 보류

주의:
이 파일은 198개 전체 특약을 확정 추출한 완성본이 아니라, 전체 확장을 위한 구조와 주요 치료 특약 1차 배치입니다.


v10 변경: 고객 목록에서 갱신형/LH형 중복 카드를 DISPLAY_GROUP 하나로 합침. 상세화면에서 가입 형태 탭으로 세부조건을 분리. 원본 rider DB는 합치지 않음.
